   - `grid_tools.py.query_knowledge` 改为：精确键 → 别名双向子串 → 标题/正文，并按相关度排序（别名精确命中优先）。
   - 新增 `power_flow` 知识点，显式列出潮流工具输入参数（algorithm / max_iteration / tolerance / 基准容量 / 机组负荷设定），覆盖测评示例4。
2. **元件引用解析增强**（`_resolve_element_id` + 新增 `_by_index_or_position`）：
   - 支持"类型+序号"引用，如"线路11""母线2""发电机3"（仅当含中文类型字符时按序号解析，避免误伤英文名"Line 1-2"）。
   - 解析失败的错误信息补充可用数量与编号范围（测评示例7"线路171"在 case39 不存在时优雅提示"系统共35个line，可用编号0~34或1~35"）。
3. **智能体摘要增强**（`power_agent.py._generate_summary`）：
   - `get_element_params` 摘要补充连接信息（线路连接 Bus X↔Bus Y、变压器高/低压侧、元件所在母线）——覆盖测评示例1"线路11连接哪两个母线"。
   - `query_knowledge` 摘要补充正文要点（含关键数值如 0.95~1.05）——覆盖测评示例2/3。
4. **复合任务路由修复**（`_parse_question` + 新增 `_is_composite_intent`）：
   - LLM 不会输出内部复合工具名 `_composite_n1_rank`，导致"关键线路逐一故障并排序"被误路由为普通 `rank_elements`。
   - 新增关键词强制覆盖：问题含"逐一/逐条"+"排序"+"N-1/故障/安全"时强制走 `_composite_n1_rank` 编排——覆盖测评示例8。

5. **短路电流计算 bug 修复**（`grid_tools.py.run_short_circuit_analysis`）：
   - 根因：旧代码调用 `pp.run_sc(...)`，而 pandapower 3.4 已移除该函数（正确 API 为 `from pandapower.shortcircuit import calc_sc`，参数 `fault=` 非 `sc_type=`，结果写入 `net.res_bus_sc` 而非返回值）。
   - 新增 `_ensure_short_circuit_params()`：回填 3.4 IEC60909 短路模型所需参数——`ext_grid` 的 `s_sc_max_mva`(1000)/`rx_max`(0.1)；`gen` 的 `vn_kv`(取所连母线电压)/`xdss_pu`(0.2)/`rdss_ohm`(0)/`pg_percent`(0)/`cos_phi`(0.95)/`sn_mva`(case39 中全为 NaN，用 max_p_mw/cos_phi 回补)；以及零序网络（线路 R0≈3R1、X0≈3X1、C0≈2.5C1；变压器 vk0/vkr0/mag0 等），以支持 1ph 单相接地。
   - 故障类型映射 3phase/2phase/1phase → 3ph/2ph/1ph；单母线支持按名称或内部索引解析；`ip/ith` 的 NaN 经 `np.nan_to_num` 处理，输出均为合法 JSON。
   - 现 3ph/2ph/1ph 三种故障、全电网与单母线均已验证通过（case39，无 AttributeError）。
