📋 节点说明

agent — 调用 LLM（绑定 17 个 @tool），是整个状态机的核心驱动节点
inject_session — 工具执行前给每个 tool_call.args 注入 session_id，实现多会话隔离
tools — 批量执行 LLM 决定调用的工具，由 GraphService._tools_node 实现
skill_check — 工具执行后检查是否需要触发 Skill 旁路（如断线后自动消过载）
Skill 旁路 — 声明式 steps 驱动的确定性闭环，不走 LLM，过程完全可审计
菱形判断 — 条件边，决定走哪条路径
